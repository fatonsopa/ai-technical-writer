# Requested capability

Compliance reviewers need to download audit entries for one selected account as JSON for an external review. Agreed behavior: AUDIT-01 includes only that selected account's entries; AUDIT-02 denies export to ordinary members; AUDIT-03 reports an export failure without a success message.

This is new functionality. A task does not yet exist. Retention changes, bulk exports across accounts, and changes to review permissions are outside scope. Repository paths, owner, release date, performance target, export-size limit, implementation and test outcomes are not supplied.
