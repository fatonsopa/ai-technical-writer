# Source facts

Draft rules for staging backups: operators must verify the backup before deployment and must not deploy if it is incomplete. A named incident commander may approve skipping the staging rehearsal only; this never waives backup verification. Definitions: rehearsal means trial deployment, verification means confirming the backup is complete. Principles: recoverability and explicit exceptions. Nothing approved or tested.
